# Example: Shifter on Electricity Dataset

This folder contains example artifacts for the CTGAN-based distribution shifter, originally from the [latent-tabular-lens](https://github.com/Naramerk/latent-tabular-lens) repository.

## Contents

| File | Description |
|------|-------------|
| `shifter_electricity_demo.ipynb` | Jupyter notebook demonstrating the shifter on the Electricity dataset |
| `synthetic_shifted.csv` | Synthetic shifted dataset generated by the CTGAN shifter |
| `shifter.pt` | Trained Shifter model weights (PyTorch) |
| `trained_ctgan_iris.pkl` | Trained CTGAN model on Iris dataset (pickle) |

> **Note:** Large binary files (`shifter.pt`, `trained_ctgan_iris.pkl`) and large data files (`synthetic_shifted.csv`, `shifter_electricity_demo.ipynb`) are stored in the original source repository and are not reproduced here due to size constraints. They can be accessed at:
> https://github.com/Naramerk/latent-tabular-lens/tree/main/shifter/example

## Usage

To run the demo notebook:

```bash
# Install dependencies
pip install -r ../requirements.txt

# Launch Jupyter
jupyter notebook shifter_electricity_demo.ipynb
```

The notebook demonstrates:
1. Loading the Electricity dataset
2. Training a CTGAN model
3. Applying the distribution shifter to generate OOD samples
4. Evaluating the shift quality using meta-features
